# Scroll — Roblox Spec

**Size:** ~2.28 studs long × 0.72 studs diameter (hand-held prop)
**Parts:** 4 mesh objects, 3 colors

## Parts & Colors

| Object | Material | Color | Hex |
|---|---|---|---|
| Scroll_Roll | M_Parchment | Aged Tan | #C8A060 |
| Scroll_Cap_L | M_Wood | Dark Brown | #47230A |
| Scroll_Cap_R | M_Wood | Dark Brown | #47230A |
| Scroll_Tie | M_Tie | Deep Red | #8C1414 |

## Studio Notes
- Import `Scroll.fbx` — 4 separate mesh parts
- Set each part's `Color` property to the hex value above
- Scroll lies horizontally along the X axis
- **Scroll_Cap_L / Scroll_Cap_R** are the wooden end caps — slightly wider than the roll
- **Scroll_Tie** is the red ribbon band around the middle
- Designed as a hand-held item — attach to character hand bone or use as a tool prop
- Scale is 1 FBX unit = 1 Roblox stud — no rescaling needed on import

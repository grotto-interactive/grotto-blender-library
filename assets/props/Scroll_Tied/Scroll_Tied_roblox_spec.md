# Scroll_Tied — Roblox Spec

**Size:** ~2.0 studs long × 0.60 studs diameter (hand-held prop)
**Parts:** 5 mesh objects, 5 colors

## Parts & Colors

| Object | Material | Color | Hex |
|---|---|---|---|
| Scroll_Roll | M_Parchment | Outer parchment (aged tan) | #C8A060 |
| Scroll_Layer_2 | M_Layer2 | Second roll layer | #B38F52 |
| Scroll_Layer_3 | M_Layer3 | Third roll layer | #997842 |
| Scroll_Core | M_Core | Innermost core | #7A5C2E |
| Scroll_Tie | M_Tie | Red ribbon | #8C1414 |

## Studio Notes
- Import `Scroll_Tied.fbx` — 5 separate mesh parts
- Set each part's `Color` property to the hex value above
- **Scroll_Roll** is the outer parchment with rough/worn ends
- **Scroll_Layer_2 / Layer_3 / Core** are inner concentric layers visible as rings from the ends — graduating darker shades inward
- **Scroll_Tie** is the red ribbon band wrapped around the middle
- Scroll lies horizontally along the X axis
- Designed as a hand-held item — attach to character hand bone or use as a tool prop
- Scale is 1 FBX unit = 1 Roblox stud — no rescaling needed on import

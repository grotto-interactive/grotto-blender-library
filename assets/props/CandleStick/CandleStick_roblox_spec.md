# CandleStick — Roblox Spec

**Size:** ~1.5 studs tall (hand-held prop)  
**Parts:** 8 mesh objects, each 1 material = 1 color

## Studio Notes
- Import `CandleStick.fbx` — 8 separate mesh parts will come in
- Set each part's `Color` property to the hex value above
- Designed as a hand-held item — attach to character hand bone or use as a tool prop
- Scale is 1 FBX unit = 1 Roblox stud — no rescaling needed on import
